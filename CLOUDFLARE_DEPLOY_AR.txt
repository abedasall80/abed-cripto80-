دليل النشر الصحيح — AbuAlAsal Quant Fusion AI PRO v3.3.1
=========================================================

هذه حزمة كاملة وليست ملفات واجهة فقط. تحتوي على:
- site/: ملفات الواجهة العربية.
- worker/: عامل Cloudflare الذي يعرض الواجهة ويوصل طلبات /api إلى خادم Python.
- python_engine/: خادم FastAPI (إذا كان منشورًا عندك بالفعل فلا تعِد نشره).
- tests/: اختبارات المشروع.

مهم جدًا: لا ترفع ملفات site الخمسة وحدها عبر Pages > Upload assets إذا أردت أن تعمل واجهات API؛ هذا ينشر ملفات ثابتة فقط ولا ينشر كود العامل الوسيط.

الطريقة المعتمدة لهذه الحزمة:
1) فك ضغط الملف كاملًا إلى مجلد عادي على Windows.
2) تأكد من تثبيت Node.js إصدار LTS. لا حاجة لإعادة تثبيت Python إذا كان خادمك الخارجي يعمل بالفعل.
3) افتح المجلد worker داخل الحزمة.
4) شغّل DEPLOY_WINDOWS.bat. سيطلب تسجيل الدخول إلى Cloudflare ثم ينشر العامل باسم abu-alasal-quant-fusion-v33. لا تحذف العاملين القديمين.
5) بعد نجاح النشر، افتح لوحة Cloudflare > Workers & Pages > abu-alasal-quant-fusion-v33 > Settings > Variables and Secrets.
6) أضف متغيرًا نصيًا غير سري باسم PYTHON_API_ORIGIN، واجعل قيمته عنوان خدمة Python العام فقط، مثل https://اسم-الخدمة.onrender.com — من دون /health أو /api أو أي مسار. احفظ التغيير وأعد النشر إذا طلبت لوحة Cloudflare ذلك.
7) افتح عنوان العامل الجديد وأضف /health. يجب أن ترى JSON فيه status: ok وpython_api_configured: true.
8) افتح العنوان نفسه مع /api/status. يجب أن ترى JSON صادرًا عن خدمة Python. إذا ظهر 503 فمتغير PYTHON_API_ORIGIN غير مضبوط، وإذا ظهر 502 فتحقق من رابط خدمة Python، وإذا ظهر 404 فغالبًا لم يتم نشر العامل الصحيح أو أن الطلب وصل إلى مشروع Pages الثابت بدل العامل.
9) بعد نجاح الفحصين فقط، افتح الصفحة الرئيسية للعامل واختبر زر «فحص الخادم» ثم «اختبار مزود البيانات».

اختبار خدمة Python مباشرةً:
- https://رابط-خدمة-Python/health
- https://رابط-خدمة-Python/api/status

لا تشارك كلمات المرور أو رموز API. لا تضع OANDA_API_TOKEN أو أي سر داخل ملفات الواجهة أو config.js.

حدود التحقق: نجاح الاختبارات المحلية لا يثبت وحده نجاح الاتصال الخارجي. لا تعتبر النشر مكتملًا إلا بعد نجاح /health و/api/status واختبار مزود البيانات.
