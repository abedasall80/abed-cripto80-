# AbuAlAsal Quant Fusion AI PRO — v3.3.1

حزمة كاملة للتجربة المحلية ثم النشر المنفصل: واجهة عربية (`site`)، محرك Python/FastAPI (`python_engine`)، وسيط Cloudflare (`worker`)، واختبارات (`tests`).

ابدأ بقراءة `START_HERE_AR.md`. على Windows شغّل `setup_windows.bat` أولًا، ثم `start_windows.bat`. لا تفتح `site/index.html` مباشرةً من القرص؛ افتح `http://127.0.0.1:8080` بعد تشغيل السكربت.

لا تحذف أي نشر قديم قبل نجاح اختبار النسخة الجديدة.
